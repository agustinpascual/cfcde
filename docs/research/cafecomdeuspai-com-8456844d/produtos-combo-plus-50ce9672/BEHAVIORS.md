# Behaviors

- Gallery: clicking a thumbnail replaces the primary image; active thumbnail has a dark border.
- Quantity: minus and plus adjust the product quantity, minimum 1.
- Purchase: the source currently reports out of stock. Per user requirement, the clone adds the item and opens the cart drawer from the right.
- Cart: overlay click and close icon dismiss it; quantity controls update subtotal; checkout navigates to `/checkout`.
- Cookie bar: `Entendi` dismisses it.
- Description: desktop accordion toggles via click; mobile content remains visible.
- Header/search/navigation links have simple opacity/color hover states.
- Responsive: desktop product grid becomes a single column below ~768px; navigation collapses to icons; footer columns become rows.
