# Page topology

1. Promo bar — static, full width, black.
2. Header — desktop horizontal navigation; mobile compact menu/logo/icons.
3. Product area — breadcrumb, click-driven gallery, title, price, quantity and purchase.
4. Product description — accordion heading on desktop, expanded content; expanded directly on mobile.
5. Reviews — static empty state with review CTA.
6. Recommendations — horizontal card rail; arrows on desktop.
7. Footer — four columns on desktop and collapsed rows on mobile.
8. Cookie bar — fixed at viewport bottom until accepted.
9. Cart drawer — click-driven, fixed overlay entering from right, quantity controls and checkout action.

The page uses the document scroll. No scroll snapping or smooth-scroll library was observed.
