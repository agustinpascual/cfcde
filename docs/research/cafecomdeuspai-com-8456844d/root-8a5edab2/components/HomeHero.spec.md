# HomeHero specification

- Target: `HomeHero.tsx`
- Screenshot: `desktop-loaded-full.png`, top viewport.
- Header reuses same visual vocabulary as Combo Plus but overlays/attaches to hero.
- Hero uses `asset-003.webp` and `asset-004.webp` desktop, `asset-005.webp` mobile.
- Time-driven autoplay every 5 seconds plus dots. CTA button links to product/category destination.
- Desktop hero height roughly 450px at content width; mobile portrait aspect and compact header.
