# Home specification

## Reference
- Desktop: `desktop-loaded-full.png`
- Mobile: `mobile-loaded-full.png`
- Interaction model: time-driven hero; click-driven rails, menu, newsletter, cookies, and cart.

## Layout
- Black 32–40px promo strip; white header overlaying/top of hero.
- Hero spans viewport width, desktop aspect near 1185/450; mobile uses portrait art.
- Content max-width about 1260px. Product rails show four desktop cards and about two mobile cards.
- Product cards: square image, uppercase 11–12px name, bold price, installment line, optional stars.
- Two promo banners split evenly with 20px gap.
- Author block: image left, uppercase heading and biography right.
- Imperdível section `#f3f3f3`, generous vertical padding.
- Newsletter in pale gray rounded panel; two fields and black submit button.
- Media gallery: five tall rounded images in one row; horizontally clipped/scrollable mobile.
- Footer matches shared Café com Deus Pai footer.

## Responsive
- Below 768px hero portrait, header compact, rails overflow horizontally, promo and author blocks stack, footer accordions.
