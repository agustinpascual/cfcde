# Behaviors

- Hero cycles automatically and can be changed with navigation dots/arrows; desktop and mobile use distinct art.
- Product sections are horizontal rails with previous/next controls; product cards link to detail routes.
- Header collapses to menu/search icons below 768px; mobile menu opens as an overlay.
- Newsletter validates the email field and shows a local success state.
- Cookie notice is dismissible. WhatsApp button is a fixed external link.
- Header cart opens the same right-side cart drawer used on the Combo Plus page.
- Footer sections are columns on desktop and collapsible rows on mobile.
